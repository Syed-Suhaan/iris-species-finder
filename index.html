Iris Species Finder

A Shiny app that names an iris flower from four measurements

Syed Suhaan
Developing Data Products, course project

Which iris is it?

Three iris species look alike. Botanists separate them by measuring petals and sepals.

R ships with 150 labelled flowers. Their average measurements, computed live for this slide:

aggregate(. ~ Species, data = iris, FUN = mean)

##      Species Sepal.Length Sepal.Width Petal.Length Petal.Width
## 1     setosa        5.006       3.428        1.462       0.246
## 2 versicolor        5.936       2.770        4.260       1.326
## 3  virginica        6.588       2.974        5.552       2.026

The averages differ, but individual flowers overlap. A guess needs a method.

How the app decides

The method is k-nearest neighbours: measure the distance to all 150 known flowers, keep the k closest, and let them vote.

z <- scale(iris[, 1:4])   # one common scale for all four measurements
knn_guess <- function(d, k) {
  nearest <- as.character(iris$Species[order(d)[1:k]])
  votes <- table(nearest)
  tied <- names(votes)[votes == max(votes)]
  nearest[nearest %in% tied][1]
}
new_flower <- (c(5.9, 2.8, 4.5, 1.4) - attr(z, "scaled:center")) / attr(z, "scaled:scale")
d <- sqrt(rowSums(sweep(z, 2, new_flower)^2))
knn_guess(d, k = 7)

## [1] "versicolor"

Does it work?

Hide each known flower in turn and guess it from the other 149. At the app’s default of k = 7 that is right 96.0% of the time. The best k tested is 12 at 96.7%.

What you can do in the app

  • Move four sliders, or load a typical flower of each species.
  • See the predicted species update as you drag.
  • Watch the vote table and a plot with the k closest flowers circled.
  • Change k and the scaling option, and see the accuracy check respond.
  • Read the built-in Documentation tab. No R knowledge needed.
